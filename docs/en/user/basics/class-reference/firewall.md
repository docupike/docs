# Firewall

The **Firewall** class documents firewalls that protect networks and control traffic between them.
Objects carry the host name and network device data.

## Usage

-   **Network role**: Record type and operating mode in _Network device_.
-   **Identification**: Record the name in _Host name_.
-   **Extensible**: Assign further categories such as _IP networking_ or _Location_ to the class if needed.

## Collections

By default, the class belongs to the following collections:

-   Network device

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Host name
-   Network device
