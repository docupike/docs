# Virtual machine

The **Virtual machine** class documents virtual machines.
Objects carry network and access data, the operating system, installed software, and commercial data.

## Usage

-   **Software**: Document the guest operating system and installed applications.
-   **Network**: Record IP addresses in _IP networking_ and access in _Access_.
-   **Responsibilities**: Link the owner or operating team in _Contacts_ and track cost in _Accounting_.

## Collections

By default, the class belongs to the following collections:

-   Hardware

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Access
-   IP networking
-   Accounting
-   Warranty
-   Contacts
-   Installed OS
-   Installed software
