# Cable

The **Cable** class documents individual cables, for example power or data cables.
Besides the location, each cable carries technical data, commercial data, and the responsible contacts.

## Usage

-   **Technical data**: Record cross section, material, number of cores, and fastening in _Cable information_.
-   **Placement**: Assign the cable to its room or building via _Location_.
-   **Procurement**: Track vendor, model, cost, and warranty in _Model_, _Accounting_, and _Warranty_.

## Collections

By default, the class belongs to the following collections:

-   Infrastructure
-   Supply

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Location
-   Cable information
-   Accounting
-   Model
-   Warranty
-   Contacts
