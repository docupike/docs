# Wiring system

The **Wiring system** class documents a cabling system as a whole, for example the backbone of a building.
Each object is placed in the location tree.

## Usage

-   **Placement**: Assign the wiring system to the building or area it covers via _Location_.
-   **Structure**: Document the system as a whole in addition to the individual cables, conduits, and cable trays.

## Collections

By default, the class belongs to the following collections:

-   Infrastructure

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Location
