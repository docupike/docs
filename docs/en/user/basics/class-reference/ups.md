# UPS

The **UPS** class documents uninterruptible power supplies that protect devices against short outages and voltage fluctuations.
Objects carry their size, an optional management IP address, and their location.

## Usage

-   **Placement**: Place the UPS in its rack or room via _Location_.
-   **Size**: Record rack units, dimensions, and weight in _Form factor_.
-   **Management access**: Document the network management card in _IP networking_.

## Collections

By default, the class belongs to the following collections:

-   Infrastructure

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Form factor
-   IP networking
-   Location
