# Multi-function device

The **Multi-function device** class documents devices that combine printing, scanning, copying, and faxing.
Objects carry printer data, network and access data, location, and commercial data.

## Usage

-   **Printer data**: Record type, color, duplex, and paper format in _Printer_.
-   **Network**: Document the IP address in _IP networking_ and the web interface in _Access_.
-   **Assets**: Track vendor, cost, and warranty in _Model_, _Accounting_, and _Warranty_.

## Collections

By default, the class belongs to the following collections:

-   Hardware

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Access
-   IP networking
-   Location
-   Model
-   Printer
-   Accounting
-   Warranty
