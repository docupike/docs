# Router

The **Router** class documents routers that connect networks, sites, and the internet.
Objects carry network device data, IP addresses, access, location, firmware, and commercial data.

## Usage

-   **Network role**: Record type and operating mode in _Network device_ and the name in _Host name_.
-   **Addressing**: Document the IP addresses in _IP networking_.
-   **Placement**: Place the router in its rack via _Location_ and record its size in _Form factor_.
-   **Assets**: Track firmware, vendor, cost, and warranty.

## Collections

By default, the class belongs to the following collections:

-   Hardware
-   Network device

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Access
-   Form factor
-   IP networking
-   Location
-   Model
-   Accounting
-   Contacts
-   Warranty
-   Installed OS
-   Installed software
-   Host name
-   Network device
