# Emergency power system

The **Emergency power system** class documents generators and similar systems that take over the power supply during an outage.
Objects carry location, model, commercial, and warranty data together with the responsible contacts.

## Usage

-   **Placement**: Assign the system to the building or room it protects via _Location_.
-   **Asset data**: Record vendor, serial number, cost, and warranty in _Model_, _Accounting_, and _Warranty_.
-   **Responsibilities**: Link the maintenance provider in _Contacts_.

## Collections

By default, the class belongs to the following collections:

-   Infrastructure

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Location
-   Accounting
-   Model
-   Warranty
-   Contacts
