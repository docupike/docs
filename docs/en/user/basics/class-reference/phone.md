# Phone

The **Phone** class documents desk phones and other conventional telephones.
Objects are placed at a location and linked to their contacts.

## Usage

-   **Placement**: Assign the phone to its room via _Location_.
-   **Assignment**: Link the user or responsible team in _Contacts_.
-   **Firmware**: Record the firmware in _Installed OS_.

## Collections

By default, the class belongs to the following collections:

-   Hardware

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Location
-   Contacts
-   Installed OS
