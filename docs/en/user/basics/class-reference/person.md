# Person

The **Person** class documents employees and external contacts.
Objects carry contact data, the employer, group memberships, and show where the person is assigned as a contact.

## Usage

-   **Contact data**: Store address, phone numbers, and email in _Address and contact_.
-   **Organization**: Link the employer in _Employee_ and teams in _Person groups_.
-   **Responsibilities**: _Contacts (linked objects)_ lists every object the person is responsible for.

## Collections

By default, the class belongs to the following collections:

-   Contact

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Address and contact
-   Employee
-   Contacts (linked objects)
-   Person groups
