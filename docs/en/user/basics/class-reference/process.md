# Process

The **Process** class documents business and IT processes.
Objects carry process details such as type, target, and SLA, and name the responsible contacts.

## Usage

-   **Process details**: Record type, target, number, SLA, and existing conditions in _Process details_.
-   **Responsibilities**: Link the process owner in _Contacts_.

## Collections

By default, the class does not belong to any collection.

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Process details
-   Contacts
