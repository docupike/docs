# Fiber channel switch

The **Fiber channel switch** class documents Fibre Channel switches that connect servers and storage in a SAN.
Objects carry access, network, location, commercial, and firmware data.

## Usage

-   **Placement**: Place the switch in its rack via _Location_ and record its rack units in _Form factor_.
-   **Management**: Document the management IP address in _IP networking_ and the access URL in _Access_.
-   **Firmware and assets**: Record the firmware in _Installed OS_ and cost and warranty in _Accounting_ and _Warranty_.

## Collections

By default, the class belongs to the following collections:

-   Hardware

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Access
-   Form factor
-   IP networking
-   Location
-   Accounting
-   Warranty
-   Installed OS
