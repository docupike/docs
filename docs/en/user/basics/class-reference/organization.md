# Organization

The **Organization** class documents companies, departments, and external partners such as vendors or service providers.
Objects carry address data, list their employees, and show where they are assigned as a contact.

## Usage

-   **Address**: Store address and contact data in _Address and contact_.
-   **Employees**: _Employees (linked objects)_ lists the people who belong to the organization.
-   **Assignments**: _Contacts (linked objects)_ lists every object the organization is responsible for.

## Collections

By default, the class belongs to the following collections:

-   Contact

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Address and contact
-   Employees (linked objects)
-   Contacts (linked objects)
