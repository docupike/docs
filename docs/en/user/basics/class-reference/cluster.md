# Cluster

The **Cluster** class documents server, database, or virtualization clusters as one logical unit.
The cluster object carries location and software data, while the member systems are documented as separate objects.

## Usage

-   **Logical unit**: Represent a group of servers or hosts as one object in the CMDB.
-   **Software**: Record cluster software and operating system in _Installed OS_ and _Installed software_.
-   **Location**: Assign the cluster to its room or building via _Location_.

## Collections

By default, the class belongs to the following collections:

-   Hardware

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Location
-   Installed OS
-   Installed software
