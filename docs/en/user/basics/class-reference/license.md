# License

The **License** class documents software licenses.
Objects carry commercial data such as order and invoice details and cost.

## Usage

-   **Commercial data**: Record inventory number, cost center, investment cost, and order data in _Accounting_.
-   **License management**: Document each license or license package as its own object.

## Collections

By default, the class belongs to the following collections:

-   Information

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Accounting
