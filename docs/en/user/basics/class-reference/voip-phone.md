# VoIP phone

The **VoIP phone** class documents IP phones.
Objects carry an IP address, firmware, location, and contacts.

## Usage

-   **Network**: Record the IP address in _IP networking_.
-   **Placement**: Assign the phone to its room via _Location_.
-   **Assignment**: Link the user in _Contacts_ and record the firmware in _Installed OS_.

## Collections

By default, the class belongs to the following collections:

-   Hardware

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   IP networking
-   Location
-   Contacts
-   Installed OS
