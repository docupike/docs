# Network

The **Network** class documents IP networks (layer 3).
Objects carry the network definition and show which IP addresses are assigned to which objects.

## Usage

-   **Network definition**: Record network address, subnet mask, default router, and supernet in _Network definition_.
-   **IP address management**: _IP addresses_ lists the addresses in the network and lets you assign or unassign them.
-   **Structure**: _Subnetworks_ lists the networks below this network, and _DHCP scopes_ holds its DHCP ranges.

## Collections

By default, the class belongs to the following collections:

-   Network

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Network definition
-   IP addresses
-   Subnetworks
-   DHCP scopes
