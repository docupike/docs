# Appliance

The **Appliance** class documents preconfigured hardware appliances, for example security, backup, or storage gateways.
Objects carry network data, access information, location, commercial data, and the installed software.

## Usage

-   **Network and access**: Document IP addresses in _IP networking_ and the management URL and credentials in _Access_.
-   **Placement**: Place the appliance in its rack via _Location_ and record its size in _Form factor_.
-   **Software**: Record the firmware or operating system in _Installed OS_ and additional software in _Installed software_.
-   **Asset data**: Track vendor, serial number, cost, and warranty in _Model_, _Accounting_, and _Warranty_.

## Collections

By default, the class belongs to the following collections:

-   Hardware

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Access
-   Form factor
-   IP networking
-   Location
-   Model
-   Accounting
-   Contacts
-   Warranty
-   Installed OS
-   Installed software
