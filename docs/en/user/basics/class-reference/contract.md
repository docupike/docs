# Contract

The **Contract** class documents contracts such as maintenance, support, leasing, or license agreements.
Contracts are linked to the objects they cover, so you can see which assets a contract applies to.

## Usage

-   **Contract data**: Record the contract details in _Contract_.
-   **Covered objects**: _Contract (linked objects)_ lists every object assigned to the contract.
-   **Contacts**: Link the contract partner and the internal owner in _Contacts_.

## Collections

By default, the class belongs to the following collections:

-   Information

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Contract
-   Contract (linked objects)
-   Contacts
