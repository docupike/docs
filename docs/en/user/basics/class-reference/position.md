# Position

The **Position** class documents generic positions or sites that do not fit a building, floor, or room.
A position is a location container with its own address.

## Usage

-   **Location hierarchy**: Place the position in the location tree and use it as the parent for other objects.
-   **Address**: Store the address in _Address and contact_.
-   **Overview**: _Location (linked objects)_ lists every object at the position.

## Collections

By default, the class belongs to the following collections:

-   Location

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Location (linked objects)
-   Location
-   Address and contact
