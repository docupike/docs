# Floor

The **Floor** class documents the floors of a building.
A floor is a location container between building and room, so you can structure large buildings by level.

## Usage

-   **Location hierarchy**: Place the floor in its building and use it as the parent for rooms.
-   **Overview**: _Location (linked objects)_ lists every object on the floor.

## Collections

By default, the class belongs to the following collections:

-   Infrastructure

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Location (linked objects)
-   Location
