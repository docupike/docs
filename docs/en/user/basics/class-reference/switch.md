# Switch

The **Switch** class documents network switches in the LAN and data center.
Objects carry network device data, IP addresses, access, location, firmware, and commercial data.

## Usage

-   **Network role**: Record type and operating mode in _Network device_ and the name in _Host name_.
-   **Management**: Document the management IP address in _IP networking_ and access in _Access_.
-   **Placement**: Place the switch in its rack via _Location_ and record its rack units in _Form factor_.
-   **Assets**: Track firmware, vendor, cost, and warranty.

## Collections

By default, the class belongs to the following collections:

-   Hardware
-   Network device

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Access
-   Form factor
-   IP networking
-   Location
-   Model
-   Accounting
-   Contacts
-   Warranty
-   Installed OS
-   Network device
-   Host name
