# Service

The **Service** class documents IT services, for example email, file storage, or an ERP system as a service.
Objects name the responsible contacts.

## Usage

-   **Service catalog**: Represent each service you offer as its own object.
-   **Responsibilities**: Link the service owner and support team in _Contacts_.

## Collections

By default, the class belongs to the following collections:

-   Information

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Contacts
