# Cellular phone

The **Cellular phone** class documents mobile phones and smartphones.
Objects carry network and access data, commercial and warranty data, and the mobile operating system.

## Usage

-   **Device data**: Record the mobile operating system in _Installed OS_ and network data in _IP networking_.
-   **Asset data**: Track inventory number, cost, and warranty in _Accounting_ and _Warranty_.
-   **Location**: Assign the phone to a site or room via _Location_.

## Collections

By default, the class belongs to the following collections:

-   Hardware

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Access
-   IP networking
-   Accounting
-   Location
-   Warranty
-   Installed OS
