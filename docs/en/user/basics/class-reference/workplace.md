# Workplace

The **Workplace** class documents individual workplaces or desks.
A workplace is placed in a room and represents the spot where clients, monitors, and phones are used.

## Usage

-   **Placement**: Place the workplace in its room via _Location_.
-   **Desk planning**: Document each desk of an office as its own object in the room.

## Collections

By default, the class belongs to the following collections:

-   Infrastructure

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Location
