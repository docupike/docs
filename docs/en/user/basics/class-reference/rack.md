# Rack

The **Rack** class documents racks and cabinets in data centers and distribution rooms.
A rack is a location container: servers, switches, patch panels, and PDUs are placed inside it, and the rack itself sits in a room.

## Usage

-   **Placement**: Place the rack in its room via _Location_.
-   **Size**: Record the rack units and dimensions in _Form factor_.
-   **Contents**: _Location (linked objects)_ lists every device installed in the rack.

## Collections

By default, the class belongs to the following collections:

-   Infrastructure

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Location (linked objects)
-   Form factor
-   Location
