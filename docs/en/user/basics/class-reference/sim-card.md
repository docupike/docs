# SIM card

The **SIM card** class documents SIM cards used in mobile phones, routers, and other cellular devices.
By default, the class has only the _General_ category.
An administrator can assign further categories to the class.

## Usage

-   **Inventory**: Keep track of every SIM card as its own object.
-   **Basic data**: Record description, purpose, lifecycle stage, and tags in _General_.
-   **Extensible**: Assign additional categories to the class, for example for contracts or accounting.

## Collections

By default, the class belongs to the following collections:

-   Hardware

## Assigned categories

The following categories are assigned to the class by default:

-   General
