# Tank

The **Tank** class documents tanks, for example fuel tanks for emergency generators.
Objects carry tank data, model, commercial, and warranty data together with the responsible contacts.

## Usage

-   **Tank data**: Record capacity and content in _Tank information_.
-   **Assets**: Track vendor, cost, and warranty in _Model_, _Accounting_, and _Warranty_.
-   **Responsibilities**: Link the operator or maintenance provider in _Contacts_.

## Collections

By default, the class belongs to the following collections:

-   Supply

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Tank information
-   Accounting
-   Model
-   Warranty
-   Contacts
