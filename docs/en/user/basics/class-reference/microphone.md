# Microphone

The **Microphone** class documents microphones at workplaces and in meeting rooms.
Objects carry model, commercial, and warranty data together with the responsible contacts.

## Usage

-   **Model**: Record vendor, product ID, and serial number in _Model_.
-   **Procurement and warranty**: Track inventory number, cost, and warranty end in _Accounting_ and _Warranty_.
-   **Assignment**: Link the user or responsible team in _Contacts_.

## Collections

By default, the class belongs to the following collections:

-   Input output device
-   End user system

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Accounting
-   Model
-   Warranty
-   Contacts
