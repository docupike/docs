# Network outlet

The **Network outlet** class documents network wall outlets.
Each outlet is placed in the location tree so you can see which room it serves.

## Usage

-   **Placement**: Assign the outlet to its room via _Location_.
-   **Room overview**: Select the room in the location tree to list all outlets placed in it.

## Collections

By default, the class belongs to the following collections:

-   Infrastructure

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Location
