# Operating system

The **Operating system** class documents operating systems such as Windows Server, Ubuntu, or macOS.
An operating system object describes the product, its editions, and versions; installations are linked to devices.

## Usage

-   **Product data**: Record the OS family in _OS_, editions in _OS edition_, and versions in _Software version_.
-   **Installations**: _OS installed on_ lists every device that runs the operating system.
-   **Contracts**: Link license or support contracts in _Contracts_.

## Collections

By default, the class belongs to the following collections:

-   Software

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Contracts
-   OS
-   OS installed on
-   OS edition
-   Software version
