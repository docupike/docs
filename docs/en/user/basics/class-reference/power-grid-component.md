# Power grid component

The **Power grid component** class documents components of the electrical installation, for example distribution boards and fuses.
Objects carry fuse protection data, model, commercial, and warranty data together with the responsible contacts.

## Usage

-   **Fuse protection**: Record the fuse protection data in _Fuse protection information_.
-   **Assets**: Track vendor, cost, and warranty in _Model_, _Accounting_, and _Warranty_.
-   **Responsibilities**: Link the operator or maintenance provider in _Contacts_.

## Collections

By default, the class belongs to the following collections:

-   Supply

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Fuse protection information
-   Accounting
-   Model
-   Warranty
-   Contacts
