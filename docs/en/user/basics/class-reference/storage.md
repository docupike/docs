# Storage Device

The **Storage Device** class documents storage systems such as SAN and NAS arrays.
Objects carry controllers and devices, network and access data, location, contracts, and commercial data.

## Usage

-   **Storage hardware**: Record controllers and disks in _Controllers_ and _Devices_.
-   **Management**: Document management IP addresses in _IP networking_ and the web interface in _Access_.
-   **Placement**: Place the system in its rack via _Location_ and record its size in _Form factor_.
-   **Contracts and assets**: Link maintenance contracts and track cost and warranty.

## Collections

By default, the class belongs to the following collections:

-   Hardware

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Access
-   Devices
-   Controllers
-   Form factor
-   IP networking
-   Location
-   Accounting
-   Warranty
-   Contracts
-   Installed OS
