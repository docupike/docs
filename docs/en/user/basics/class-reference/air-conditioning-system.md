# Air-conditioning system

The **Air-conditioning system** class documents cooling and climate units in buildings, server rooms, and data centers.
Each object is placed in the location tree and carries commercial data, model details, warranty, and the responsible contacts.

## Usage

-   **Placement**: Assign the unit to the room or building it serves via the _Location_ category.
-   **Procurement and warranty**: Record vendor, model, serial number, investment cost, and warranty end in _Model_, _Accounting_, and _Warranty_.
-   **Responsibilities**: Link the service provider or facility team in _Contacts_.

## Collections

By default, the class belongs to the following collections:

-   Infrastructure
-   Protection system

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Location
-   Accounting
-   Model
-   Warranty
-   Contacts
