# Room

The **Room** class documents rooms such as offices, server rooms, and storage rooms.
A room is a location container: racks, workplaces, and devices are placed inside it, and the room sits in a building or on a floor.

## Usage

-   **Room data**: Record purpose, room number, ceiling height, and payload in _Room_, plus usage, ownership, and size in _Location details_.
-   **Location hierarchy**: Place the room in its building or floor and use it as the parent for racks and devices.
-   **Address and contacts**: Store the address in _Address and contact_ and the responsible people in _Contacts_.
-   **Contents**: _Location (linked objects)_ lists every object in the room.

## Collections

By default, the class belongs to the following collections:

-   Infrastructure
-   Location

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Location (linked objects)
-   Location
-   Room
-   Contacts
-   Location details
-   Address and contact
