# Supplier

The **Supplier** class documents suppliers of hardware, software, and services.
Objects name the relevant contacts at the supplier.

## Usage

-   **Supplier list**: Represent each supplier as its own object.
-   **Contacts**: Link account managers and support contacts in _Contacts_.

## Collections

By default, the class does not belong to any collection.

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Contacts
