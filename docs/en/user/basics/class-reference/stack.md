# Stack

The **Stack** class documents stacks of switches or other devices that are managed as one unit.
Objects carry a management IP address and a location.

## Usage

-   **Management**: Document the shared management IP address in _IP networking_.
-   **Placement**: Assign the stack to its rack or room via _Location_.

## Collections

By default, the class belongs to the following collections:

-   Hardware

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   IP networking
-   Location
