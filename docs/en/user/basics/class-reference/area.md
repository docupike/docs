# Area

The **Area** class documents land areas and plots, for example a campus, premises, or an outdoor site.
An area is a location container; buildings and other objects can be placed on it.

## Usage

-   **Plot data**: Record cadastral office, parcel, shape, and subsoil in _Area details_.
-   **Location details**: Record usage, ownership, and size in _Location details_ and the address in _Address and contact_.
-   **Location hierarchy**: Place buildings on the area and see them in _Location (linked objects)_.

## Collections

By default, the class belongs to the following collections:

-   Location

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Location (linked objects)
-   Location
-   Area details
-   Location details
-   Address and contact
