# DBMS

The **DBMS** class documents database management systems such as MariaDB, PostgreSQL, or Microsoft SQL Server.
Database instances and schemas have their own classes.

## Usage

-   **Database landscape**: Represent each DBMS product as its own object.
-   **Contracts**: Link license or support contracts in _Contracts_.

## Collections

By default, the class belongs to the following collections:

-   Software

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Contracts
