# City

The **City** class documents cities as a level in the location tree.
A city is a location container that typically sits below a country and holds the buildings of a site.

## Usage

-   **Location hierarchy**: Place the city below a country and use it as the parent for buildings.
-   **Site overview**: Use _Location (linked objects)_ to see everything that is located in the city.

## Collections

By default, the class belongs to the following collections:

-   Infrastructure

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Location (linked objects)
-   Location
