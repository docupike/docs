# Supernetwork

The **Supernetwork** class documents address ranges that contain several IP networks.
Objects carry a network definition and list their subnetworks and DHCP scopes.

## Usage

-   **Address planning**: Record the overall range in _Network definition_.
-   **Hierarchy**: _Subnetworks_ shows every network that belongs to the supernetwork.
-   **DHCP**: Document DHCP ranges in _DHCP scopes_.

## Collections

By default, the class belongs to the following collections:

-   Network

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Network definition
-   Subnetworks
-   DHCP scopes
