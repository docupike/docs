# Monitor

The **Monitor** class documents monitors and other displays.
Objects carry display data such as size and resolution, the model, and their location.

## Usage

-   **Display data**: Record size, resolution, USB hub, and speaker in _Display_.
-   **Model**: Track vendor, product ID, and serial number in _Model_.
-   **Placement**: Assign the monitor to its room via _Location_.

## Collections

By default, the class belongs to the following collections:

-   Hardware
-   Display Device
-   End user system

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Form factor
-   Location
-   Model
-   Display
