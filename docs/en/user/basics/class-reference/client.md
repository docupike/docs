# Client

The **Client** class documents desktop PCs, notebooks, and other computers used by employees.
It covers hardware, storage, display, network, software, and commercial data.

## Usage

-   **Hardware**: Record CPU, memory, graphics card, display, controllers, devices, and volumes.
-   **Software**: Document the operating system and installed applications.
-   **Network**: Record IP addresses in _IP networking_ and the name in _Host name_.
-   **Asset management**: Track cost, warranty, contracts, and the responsible user in _Accounting_, _Warranty_, _Contracts_, and _Contacts_.

## Collections

By default, the class belongs to the following collections:

-   Hardware
-   End user system

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Access
-   Contracts
-   Display
-   Graphics card
-   Devices
-   Controllers
-   IP networking
-   Form factor
-   Memory
-   Model
-   CPU
-   Accounting
-   Volumes
-   Contacts
-   Warranty
-   Location
-   Installed OS
-   Installed software
-   Host name
