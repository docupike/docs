# Customer

The **Customer** class documents customers of your organization.
Objects carry address and contact data and show where the customer is assigned as a contact.

## Usage

-   **Address**: Store the postal address, phone numbers, and email in _Address and contact_.
-   **Assignments**: _Contacts (linked objects)_ lists every object the customer is assigned to.

## Collections

By default, the class belongs to the following collections:

-   Contact

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Address and contact
-   Contacts (linked objects)
