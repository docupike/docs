# Power distribution unit

The **Power distribution unit** class documents PDUs that distribute power inside racks.
Managed PDUs can receive an IP address, and every unit is placed in the location tree.

## Usage

-   **Rack placement**: Place the PDU in its rack via _Location_.
-   **Management access**: Document the management IP address in _IP networking_.

## Collections

By default, the class belongs to the following collections:

-   Infrastructure
-   Supply

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   IP networking
-   Location
