# Server

The **Server** class documents physical servers in data centers and server rooms.
It covers hardware, storage, network, software, and commercial data.

## Usage

-   **Hardware**: Record CPUs, memory, controllers, devices, and volumes.
-   **Software**: Document the operating system and installed applications.
-   **Network**: Record IP addresses in _IP networking_, the name in _Host name_, and management access in _Access_.
-   **Placement**: Place the server in its rack via _Location_ and record its rack units in _Form factor_.
-   **Assets**: Track vendor, cost, warranty, support contracts, and contacts.

## Collections

By default, the class belongs to the following collections:

-   Hardware

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Access
-   Accounting
-   Contracts
-   CPU
-   Devices
-   Controllers
-   Volumes
-   Form factor
-   IP networking
-   Location
-   Memory
-   Model
-   Contacts
-   Warranty
-   Installed OS
-   Installed software
-   Host name
