# Rack mount

The **Rack mount** class documents mounting frames, shelves, and similar fixtures inside a rack.
A rack mount is a location container, so devices can be placed in it.

## Usage

-   **Placement**: Place the rack mount in its rack via _Location_.
-   **Contained devices**: Place devices in the rack mount and see them in _Location (linked objects)_.

## Collections

By default, the class belongs to the following collections:

-   Infrastructure

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Location (linked objects)
-   Location
