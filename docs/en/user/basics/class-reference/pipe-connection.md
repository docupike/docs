# Pipe connection

The **Pipe connection** class documents pipe connections, for example for cooling water or extinguishing agents.
Objects carry pipe data, model, commercial, and warranty data together with the responsible contacts.

## Usage

-   **Pipe data**: Record diameter and pressure in _Pipe connection details_.
-   **Assets**: Track vendor, cost, and warranty in _Model_, _Accounting_, and _Warranty_.
-   **Responsibilities**: Link the operator or maintenance provider in _Contacts_.

## Collections

By default, the class belongs to the following collections:

-   Supply

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Pipe connection details
-   Accounting
-   Model
-   Warranty
-   Contacts
