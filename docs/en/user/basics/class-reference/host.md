# Host

The **Host** class documents physical computer systems that do not fit a more specific class such as server or client.
It covers hardware, storage, network, software, and commercial data.

## Usage

-   **Hardware**: Record CPU, memory, controllers, devices, and volumes.
-   **Software and network**: Document the operating system, installed software, and IP addresses.
-   **Placement**: Place the host in its rack or room via _Location_ and record its size in _Form factor_.
-   **Assets**: Track vendor, cost, warranty, contracts, and contacts.

## Collections

By default, the class belongs to the following collections:

-   Hardware

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Access
-   Contracts
-   IP networking
-   Form factor
-   Memory
-   Location
-   Model
-   CPU
-   Controllers
-   Accounting
-   Devices
-   Volumes
-   Contacts
-   Warranty
-   Installed OS
-   Installed software
