# Country

The **Country** class documents countries as the top level of the location tree.
A country is a location container; cities and buildings are placed below it.

## Usage

-   **Location hierarchy**: Use the country as the root for the cities and buildings of a region.
-   **Overview**: _Location (linked objects)_ lists every object placed directly in the country.

## Collections

By default, the class belongs to the following collections:

-   Infrastructure

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Location (linked objects)
