# Printer

The **Printer** class documents network and workplace printers.
Objects carry printer data, network and access data, location, contracts, and commercial data.

## Usage

-   **Printer data**: Record type, color, duplex, and paper format in _Printer_.
-   **Network**: Document the IP address in _IP networking_ and the web interface in _Access_.
-   **Contracts and assets**: Link leasing or service contracts in _Contracts_ and track cost and warranty.

## Collections

By default, the class belongs to the following collections:

-   Hardware
-   Input output device
-   End user system

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Access
-   IP networking
-   Location
-   Printer
-   Accounting
-   Warranty
-   Contacts
-   Contracts
-   Installed OS
