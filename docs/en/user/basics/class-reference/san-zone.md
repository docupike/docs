# SAN zone

The **SAN zone** class documents zones in a storage area network that define which servers may access which storage.
By default, the class has only the _General_ category.
An administrator can assign further categories to the class.

## Usage

-   **SAN structure**: Represent each zone as an object to document the logical structure of the SAN.
-   **Basic data**: Record description, purpose, lifecycle stage, and tags in _General_.
-   **Extensible**: Assign additional categories to the class if you need more attributes.

## Collections

By default, the class belongs to the following collections:

-   Hardware

## Assigned categories

The following categories are assigned to the class by default:

-   General
