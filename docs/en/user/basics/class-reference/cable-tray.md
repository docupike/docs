# Cable tray

The **Cable tray** class documents trays and racks that route cables through buildings and data centers.
Objects carry their dimensions and are placed in the location tree.

## Usage

-   **Placement**: Assign the tray to the room or building it runs through via _Location_.
-   **Dimensions**: Record width, height, depth, and weight in _Form factor_.

## Collections

By default, the class belongs to the following collections:

-   Infrastructure

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Form factor
-   Location
