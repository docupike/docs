# Daemon

The **Daemon** class documents background services such as web servers, mail servers, or agents.
Objects can be linked to contracts.

## Usage

-   **Service landscape**: Represent each daemon as its own object.
-   **Contracts**: Link support contracts in _Contracts_.

## Collections

By default, the class belongs to the following collections:

-   Software

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Contracts
