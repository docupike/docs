# Patch panel

The **Patch panel** class documents patch panels that terminate the structured cabling.
Objects carry their size in rack units and are placed in a rack or room.

## Usage

-   **Rack placement**: Place the panel in its rack via _Location_.
-   **Size**: Record rack units and dimensions in _Form factor_.

## Collections

By default, the class belongs to the following collections:

-   Infrastructure

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Form factor
-   Location
