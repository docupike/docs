# Telephone system

The **Telephone system** class documents telephone systems and PBXs.
Objects carry network and access data, location, firmware, commercial data, and contacts.

## Usage

-   **Management**: Document the IP address in _IP networking_ and the admin interface in _Access_.
-   **Placement**: Place the system in its rack or room via _Location_ and record its size in _Form factor_.
-   **Assets**: Track firmware, cost, warranty, and the service provider in _Contacts_.

## Collections

By default, the class belongs to the following collections:

-   Hardware

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Access
-   Form factor
-   IP networking
-   Location
-   Accounting
-   Warranty
-   Contacts
-   Installed OS
