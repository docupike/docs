# Electric power company

The **Electric power company** class documents the utilities that supply your sites with electric power.
Each object can be placed at a location and linked to the relevant contacts.

## Usage

-   **Placement**: Assign the company to a building or city via _Location_.
-   **Contacts**: Store account managers or the outage hotline as _Contacts_.

## Collections

By default, the class belongs to the following collections:

-   Infrastructure

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Location
-   Contacts
