# Virtualization host

The **Virtualization host** class documents physical hosts that run a hypervisor and virtual machines.
Objects carry hardware, network, location, software, and commercial data.

## Usage

-   **Hypervisor**: Record the hypervisor in _Installed OS_ and management tools in _Installed software_.
-   **Hardware**: Document controllers and devices, and record size in _Form factor_.
-   **Network and placement**: Record IP addresses in _IP networking_ and place the host in its rack via _Location_.
-   **Assets**: Track vendor, cost, warranty, and contacts.

## Collections

By default, the class belongs to the following collections:

-   Hardware

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Access
-   Accounting
-   Devices
-   Controllers
-   Form factor
-   IP networking
-   Location
-   Model
-   Contacts
-   Warranty
-   Installed OS
-   Installed software
