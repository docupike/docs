# Application

The **Application** class documents software products such as office suites, ERP systems, or tools.
An application object describes the product and its versions; installations are linked to the devices that run it.

## Usage

-   **Product data**: Record the vendor in _Software_ and the available versions in _Software version_.
-   **Installations**: _Software installed on_ lists every device where the application is installed.
-   **Contracts and cost**: Link license or support contracts in _Contracts_ and record cost in _Accounting_.

## Collections

By default, the class belongs to the following collections:

-   Software

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Accounting
-   Contracts
-   Software
-   Software installed on
-   Software version
