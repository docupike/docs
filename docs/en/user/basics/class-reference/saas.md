# SaaS

The **SaaS** class documents cloud applications that you use as a service, for example CRM or collaboration tools.
Objects carry commercial data, contracts, and contacts.

## Usage

-   **Subscriptions**: Record cost and order data in _Accounting_ and link the subscription in _Contracts_.
-   **Responsibilities**: Link the vendor and internal owner in _Contacts_.

## Collections

By default, the class belongs to the following collections:

-   Software

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Accounting
-   Contacts
-   Contracts
