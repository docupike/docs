# Tape library

The **Tape library** class documents tape libraries used for backup and long-term archiving.
Objects carry drives and controllers, a management IP address, and a location.

## Usage

-   **Drives**: Record tape drives and controllers in _Devices_ and _Controllers_.
-   **Management**: Document the management IP address in _IP networking_.
-   **Placement**: Place the library in its rack or room via _Location_.

## Collections

By default, the class belongs to the following collections:

-   Hardware

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Devices
-   Controllers
-   IP networking
-   Location
