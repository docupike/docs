# Faceplate

The **Faceplate** class documents faceplates and blanking panels that cover unused rack units.
Objects carry their size and are placed in a rack.

## Usage

-   **Rack planning**: Place the faceplate in its rack via _Location_.
-   **Size**: Record the rack units in _Form factor_.

## Collections

By default, the class belongs to the following collections:

-   Hardware

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Form factor
-   Location
