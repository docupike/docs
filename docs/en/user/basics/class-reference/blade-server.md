# Blade server

The **Blade server** class documents server modules that run inside a blade chassis.
It covers CPU, memory, storage, network, software, and commercial data.

## Usage

-   **Hardware**: Record CPUs, memory, and storage in _CPU_, _Memory_, _Controllers_, _Devices_, and _Volumes_.
-   **Placement**: Place the blade in its chassis via _Location_.
-   **Software and network**: Document the operating system, installed software, and IP addresses.
-   **Contracts and assets**: Link support contracts in _Contracts_ and track cost and warranty in _Accounting_ and _Warranty_.

## Collections

By default, the class belongs to the following collections:

-   Hardware

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Access
-   Contracts
-   CPU
-   Devices
-   Controllers
-   IP networking
-   Location
-   Memory
-   Model
-   Accounting
-   Volumes
-   Contacts
-   Warranty
-   Installed OS
-   Installed software
