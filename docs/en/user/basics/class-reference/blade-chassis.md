# Blade chassis

The **Blade chassis** class documents enclosures that hold blade servers and shared components such as power and cooling.
A blade chassis is a location container: blade servers are placed inside it, and the chassis sits in a rack.

## Usage

-   **Placement**: Place the chassis in its rack via _Location_ and record its rack units in _Form factor_.
-   **Contained blades**: Place blade servers in the chassis and see them in _Location (linked objects)_.
-   **Firmware**: Record the chassis management software in _Installed OS_.

## Collections

By default, the class belongs to the following collections:

-   Hardware

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Location (linked objects)
-   Form factor
-   Location
-   Installed OS
