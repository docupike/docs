# Power source

The **Power source** class documents sources of electric power such as grid feeds, generators, batteries, or solar systems.
Objects carry technical power data, model, commercial, and warranty data.

## Usage

-   **Power data**: Record type, delivery type, output, current, storage capacity, and energy source in _Power source information_.
-   **Assets**: Track vendor, cost, and warranty in _Model_, _Accounting_, and _Warranty_.
-   **Responsibilities**: Link the operator or maintenance provider in _Contacts_.

## Collections

By default, the class does not belong to any collection.

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Power source information
-   Accounting
-   Model
-   Warranty
-   Contacts
