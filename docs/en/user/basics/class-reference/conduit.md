# Conduit

The **Conduit** class documents conduits and empty pipes that are installed for current or future cabling.
Objects carry their dimensions and are placed in the location tree.

## Usage

-   **Placement**: Assign the conduit to the building or room it runs through via _Location_.
-   **Dimensions**: Record the physical size in _Form factor_.

## Collections

By default, the class belongs to the following collections:

-   Infrastructure

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Form factor
-   Location
