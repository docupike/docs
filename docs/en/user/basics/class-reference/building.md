# Building

The **Building** class documents the buildings of your organization.
A building is a location container: rooms, floors, and other objects are placed inside it, and the building itself is typically placed below a city or a country in the location tree.

## Usage

-   **Location hierarchy**: Place the building in the location tree and use it as the parent for floors, rooms, and devices.
-   **Address**: Store the postal address and contact numbers in _Address and contact_.
-   **Building data**: Record floors, type of construction, and basement in _Building information_, plus usage, ownership, and size in _Location details_.
-   **Overview**: _Location (linked objects)_ lists every object placed in the building.

## Collections

By default, the class belongs to the following collections:

-   Infrastructure
-   Location

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Location (linked objects)
-   Location
-   Building information
-   Location details
-   Address and contact
