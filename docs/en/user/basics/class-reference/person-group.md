# Person group

The **Person group** class documents groups of people, for example teams, departments, or on-call rotations.
A group can be assigned as a contact instead of individual people.

## Usage

-   **Members**: Add people to the group in _Person group members_.
-   **Assignments**: _Contacts (linked objects)_ lists every object the group is responsible for.

## Collections

By default, the class belongs to the following collections:

-   Contact

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Person group members
-   Contacts (linked objects)
