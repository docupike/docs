# Wireless access point

The **Wireless access point** class documents WLAN access points.
Objects carry wireless network data, network device data, IP addresses, location, and commercial data.

## Usage

-   **Wireless data**: Record SSID, encryption, band, and channel in _Wifi networks_.
-   **Network role**: Record type and operating mode in _Network device_ and the name in _Host name_.
-   **Placement**: Assign the access point to its room or floor via _Location_.
-   **Assets**: Track firmware, cost, warranty, and contacts.

## Collections

By default, the class belongs to the following collections:

-   Hardware
-   Network device

## Assigned categories

The following categories are assigned to the class by default:

-   General
-   Access
-   IP networking
-   Location
-   Wifi networks
-   Accounting
-   Contacts
-   Warranty
-   Installed OS
-   Host name
-   Network device
