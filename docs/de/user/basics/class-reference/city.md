# Stadt

Die Klasse **Stadt** dokumentiert Städte als Ebene im Standortbaum.
Eine Stadt ist ein Standort-Container, der typischerweise unterhalb eines Landes liegt und die Gebäude eines Standorts aufnimmt.

## Verwendung

-   **Standorthierarchie**: Platzieren Sie die Stadt unterhalb eines Landes und nutzen Sie sie als übergeordneten Standort für Gebäude.
-   **Standortübersicht**: Über _Standort (verknüpfte Objekte)_ sehen Sie alles, was sich in der Stadt befindet.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Infrastruktur

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Standort (verknüpfte Objekte)
-   Standort
