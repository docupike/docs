# Frontplatte

Die Klasse **Frontplatte** dokumentiert Frontplatten und Blindblenden, die ungenutzte Höheneinheiten abdecken.
Die Objekte enthalten ihre Größe und werden in einem Rack platziert.

## Verwendung

-   **Rackplanung**: Platzieren Sie die Frontplatte über _Standort_ in ihrem Rack.
-   **Größe**: Erfassen Sie die Höheneinheiten unter _Formfaktor_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Formfaktor
-   Standort
