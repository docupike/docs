# Telefon

Die Klasse **Telefon** dokumentiert Tischtelefone und andere klassische Telefone.
Die Objekte werden einem Standort zugeordnet und mit ihren Kontakten verknüpft.

## Verwendung

-   **Platzierung**: Ordnen Sie das Telefon über _Standort_ seinem Raum zu.
-   **Zuordnung**: Verknüpfen Sie die nutzende Person oder das zuständige Team unter _Kontakte_.
-   **Firmware**: Erfassen Sie die Firmware unter _Installiertes Betriebssystem_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Standort
-   Kontakte
-   Installiertes Betriebssystem
