# Stromquelle

Die Klasse **Stromquelle** dokumentiert Quellen elektrischer Energie wie Netzeinspeisungen, Generatoren, Batterien oder Solaranlagen.
Die Objekte enthalten technische Stromdaten, Modell, kaufmännische Daten und Garantie.

## Verwendung

-   **Stromdaten**: Erfassen Sie Typ, Lieferart, Leistung, Strom, Speicherkapazität und Energiequelle unter _Stromquellen Information_.
-   **Assets**: Pflegen Sie Hersteller, Kosten und Garantie unter _Modell_, _Buchhaltung_ und _Garantie_.
-   **Zuständigkeiten**: Verknüpfen Sie Betreiber oder Wartungsdienstleister unter _Kontakte_.

## Kollektionen

Standardmäßig gehört die Klasse zu keiner Kollektion.

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Stromquellen Information
-   Buchhaltung
-   Modell
-   Garantie
-   Kontakte
