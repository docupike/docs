# Rack-Montage

Die Klasse **Rack-Montage** dokumentiert Einbaurahmen, Fachböden und ähnliche Einbauten in einem Rack.
Eine Rack-Montage ist ein Standort-Container, in dem Geräte platziert werden können.

## Verwendung

-   **Platzierung**: Platzieren Sie die Rack-Montage über _Standort_ in ihrem Rack.
-   **Enthaltene Geräte**: Platzieren Sie Geräte in der Rack-Montage und sehen Sie sie unter _Standort (verknüpfte Objekte)_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Infrastruktur

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Standort (verknüpfte Objekte)
-   Standort
