# Stromnetzkomponenten

Die Klasse **Stromnetzkomponenten** dokumentiert Komponenten der Elektroinstallation, zum Beispiel Verteiler und Sicherungen.
Die Objekte enthalten Daten zur Absicherung, Modell, kaufmännische Daten und Garantie sowie die zuständigen Kontakte.

## Verwendung

-   **Absicherung**: Erfassen Sie die Absicherungsdaten unter _Sicherungsschutzinformationen_.
-   **Assets**: Pflegen Sie Hersteller, Kosten und Garantie unter _Modell_, _Buchhaltung_ und _Garantie_.
-   **Zuständigkeiten**: Verknüpfen Sie Betreiber oder Wartungsdienstleister unter _Kontakte_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Versorgung

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Sicherungsschutzinformationen
-   Buchhaltung
-   Modell
-   Garantie
-   Kontakte
