# Server

Die Klasse **Server** dokumentiert physische Server in Rechenzentren und Serverräumen.
Sie deckt Hardware, Speicher, Netzwerk, Software und kaufmännische Daten ab.

## Verwendung

-   **Hardware**: Erfassen Sie CPUs, Speicher, Controller, Geräte und Volumes.
-   **Software**: Dokumentieren Sie Betriebssystem und installierte Anwendungen.
-   **Netzwerk**: Erfassen Sie IP-Adressen unter _IP-Netzwerk_, den Namen unter _Hostname_ und den Verwaltungszugang unter _Zugriff_.
-   **Platzierung**: Platzieren Sie den Server über _Standort_ in seinem Rack und erfassen Sie die Höheneinheiten unter _Formfaktor_.
-   **Assets**: Pflegen Sie Hersteller, Kosten, Garantie, Supportverträge und Kontakte.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Zugriff
-   Buchhaltung
-   Verträge
-   CPU
-   Geräte
-   Controller
-   Volumes
-   Formfaktor
-   IP-Netzwerk
-   Standort
-   Speicher
-   Modell
-   Kontakte
-   Garantie
-   Installiertes Betriebssystem
-   Installierte Software
-   Hostname
