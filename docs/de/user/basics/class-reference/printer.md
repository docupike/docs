# Drucker

Die Klasse **Drucker** dokumentiert Netzwerk- und Arbeitsplatzdrucker.
Die Objekte enthalten Druckerdaten, Netzwerk- und Zugangsdaten, Standort, Verträge und kaufmännische Daten.

## Verwendung

-   **Druckerdaten**: Erfassen Sie Typ, Farbe, Duplex und Papierformat unter _Drucker_.
-   **Netzwerk**: Dokumentieren Sie die IP-Adresse unter _IP-Netzwerk_ und die Weboberfläche unter _Zugriff_.
-   **Verträge und Assets**: Verknüpfen Sie Leasing- oder Serviceverträge unter _Verträge_ und pflegen Sie Kosten und Garantie.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware
-   Ein-/Ausgabegerät
-   Endanwendersystem

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Zugriff
-   IP-Netzwerk
-   Standort
-   Drucker
-   Buchhaltung
-   Garantie
-   Kontakte
-   Verträge
-   Installiertes Betriebssystem
