# Stack

Die Klasse **Stack** dokumentiert Stapel aus Switches oder anderen Geräten, die als eine Einheit verwaltet werden.
Die Objekte enthalten eine Management-IP-Adresse und einen Standort.

## Verwendung

-   **Verwaltung**: Dokumentieren Sie die gemeinsame Management-IP-Adresse unter _IP-Netzwerk_.
-   **Platzierung**: Ordnen Sie den Stack über _Standort_ seinem Rack oder Raum zu.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   IP-Netzwerk
-   Standort
