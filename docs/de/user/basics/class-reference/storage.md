# Speichergerät

Die Klasse **Speichergerät** dokumentiert Speichersysteme wie SAN- und NAS-Arrays.
Die Objekte enthalten Controller und Geräte, Netzwerk- und Zugangsdaten, Standort, Verträge und kaufmännische Daten.

## Verwendung

-   **Speicherhardware**: Erfassen Sie Controller und Festplatten unter _Controller_ und _Geräte_.
-   **Verwaltung**: Dokumentieren Sie Management-IP-Adressen unter _IP-Netzwerk_ und die Weboberfläche unter _Zugriff_.
-   **Platzierung**: Platzieren Sie das System über _Standort_ in seinem Rack und erfassen Sie die Größe unter _Formfaktor_.
-   **Verträge und Assets**: Verknüpfen Sie Wartungsverträge und pflegen Sie Kosten und Garantie.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Zugriff
-   Geräte
-   Controller
-   Formfaktor
-   IP-Netzwerk
-   Standort
-   Buchhaltung
-   Garantie
-   Verträge
-   Installiertes Betriebssystem
