# Tape library

Die Klasse **Tape library** dokumentiert Bandbibliotheken für Backup und Langzeitarchivierung.
Die Objekte enthalten Laufwerke und Controller, eine Management-IP-Adresse und einen Standort.

## Verwendung

-   **Laufwerke**: Erfassen Sie Bandlaufwerke und Controller unter _Geräte_ und _Controller_.
-   **Verwaltung**: Dokumentieren Sie die Management-IP-Adresse unter _IP-Netzwerk_.
-   **Platzierung**: Platzieren Sie die Bibliothek über _Standort_ in ihrem Rack oder Raum.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Geräte
-   Controller
-   IP-Netzwerk
-   Standort
