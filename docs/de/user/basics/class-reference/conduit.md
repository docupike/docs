# Leerrohr

Die Klasse **Leerrohr** dokumentiert Leerrohre, die für aktuelle oder künftige Verkabelung verlegt sind.
Die Objekte enthalten ihre Abmessungen und werden im Standortbaum platziert.

## Verwendung

-   **Platzierung**: Ordnen Sie das Leerrohr über _Standort_ dem Gebäude oder Raum zu, durch das es verläuft.
-   **Abmessungen**: Erfassen Sie die physischen Maße unter _Formfaktor_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Infrastruktur

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Formfaktor
-   Standort
