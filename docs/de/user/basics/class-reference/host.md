# Host

Die Klasse **Host** dokumentiert physische Rechnersysteme, die nicht zu einer spezielleren Klasse wie Server oder Client passen.
Sie umfasst Hardware-, Speicher-, Netzwerk-, Software- und kaufmännische Daten.

## Verwendung

-   **Hardware**: Erfassen Sie CPU, Speicher, Controller, Geräte und Volumes.
-   **Software und Netzwerk**: Dokumentieren Sie Betriebssystem, installierte Software und IP-Adressen.
-   **Platzierung**: Platzieren Sie den Host über _Standort_ in seinem Rack oder Raum und erfassen Sie die Größe unter _Formfaktor_.
-   **Assets**: Pflegen Sie Hersteller, Kosten, Garantie, Verträge und Kontakte.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Zugriff
-   Verträge
-   IP-Netzwerk
-   Formfaktor
-   Speicher
-   Standort
-   Modell
-   CPU
-   Controller
-   Buchhaltung
-   Geräte
-   Volumes
-   Kontakte
-   Garantie
-   Installiertes Betriebssystem
-   Installierte Software
