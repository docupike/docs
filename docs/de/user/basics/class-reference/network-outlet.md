# Netzwerkdose

Die Klasse **Netzwerkdose** dokumentiert Netzwerk-Wanddosen.
Jede Dose wird im Standortbaum platziert, sodass Sie sehen, welchen Raum sie versorgt.

## Verwendung

-   **Platzierung**: Ordnen Sie die Dose über _Standort_ ihrem Raum zu.
-   **Raumübersicht**: Wählen Sie den Raum im Standortbaum aus, um alle darin platzierten Dosen aufzulisten.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Infrastruktur

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Standort
