# Lizenz

Die Klasse **Lizenz** dokumentiert Softwarelizenzen.
Die Objekte enthalten kaufmännische Daten wie Bestell- und Rechnungsangaben und Kosten.

## Verwendung

-   **Kaufmännische Daten**: Erfassen Sie Inventarnummer, Kostenstelle, Anschaffungskosten und Bestelldaten unter _Buchhaltung_.
-   **Lizenzverwaltung**: Dokumentieren Sie jede Lizenz oder jedes Lizenzpaket als eigenes Objekt.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Information

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Buchhaltung
