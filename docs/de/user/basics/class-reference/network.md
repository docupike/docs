# Netzwerk

Die Klasse **Netzwerk** dokumentiert IP-Netze (Layer 3).
Die Objekte enthalten die Netzwerkdefinition und zeigen, welche IP-Adressen welchen Objekten zugewiesen sind.

## Verwendung

-   **Netzwerkdefinition**: Erfassen Sie Netzadresse, Subnetzmaske, Standardrouter und Supernetz unter _Netzwerkdefinition_.
-   **IP-Adressverwaltung**: _IP-Adressen_ listet die Adressen im Netz und ermöglicht es, sie zuzuweisen oder die Zuweisung aufzuheben.
-   **Struktur**: _Subnetze_ listet die Netze unterhalb dieses Netzes, und _DHCP-Bereiche_ enthält seine DHCP-Bereiche.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Netzwerk

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Netzwerkdefinition
-   IP-Adressen
-   Subnetze
-   DHCP-Bereiche
