# DBMS

Die Klasse **DBMS** dokumentiert Datenbankmanagementsysteme wie MariaDB, PostgreSQL oder Microsoft SQL Server.
Für Datenbankinstanzen und Schemata gibt es eigene Klassen.

## Verwendung

-   **Datenbanklandschaft**: Bilden Sie jedes DBMS-Produkt als eigenes Objekt ab.
-   **Verträge**: Verknüpfen Sie Lizenz- oder Supportverträge unter _Verträge_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Software

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Verträge
