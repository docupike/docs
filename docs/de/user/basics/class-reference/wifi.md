# WLAN-Access Point

Die Klasse **WLAN-Access Point** dokumentiert WLAN-Access-Points.
Die Objekte enthalten WLAN-Daten, Netzwerkgerätedaten, IP-Adressen, Standort und kaufmännische Daten.

## Verwendung

-   **WLAN-Daten**: Erfassen Sie SSID, Verschlüsselung, Frequenzband und Kanal unter _WLAN-Netzwerke_.
-   **Netzwerkrolle**: Erfassen Sie Typ und Betriebsmodus unter _Netzwerkgerät_ und den Namen unter _Hostname_.
-   **Platzierung**: Ordnen Sie den Access Point über _Standort_ seinem Raum oder seiner Etage zu.
-   **Assets**: Pflegen Sie Firmware, Kosten, Garantie und Kontakte.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware
-   Netzwerkgerät

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Zugriff
-   IP-Netzwerk
-   Standort
-   WLAN-Netzwerke
-   Buchhaltung
-   Kontakte
-   Garantie
-   Installiertes Betriebssystem
-   Hostname
-   Netzwerkgerät
