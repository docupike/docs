# Switch

Die Klasse **Switch** dokumentiert Netzwerk-Switches im LAN und Rechenzentrum.
Die Objekte enthalten Netzwerkgerätedaten, IP-Adressen, Zugriff, Standort, Firmware und kaufmännische Daten.

## Verwendung

-   **Netzwerkrolle**: Erfassen Sie Typ und Betriebsmodus unter _Netzwerkgerät_ und den Namen unter _Hostname_.
-   **Verwaltung**: Dokumentieren Sie die Management-IP-Adresse unter _IP-Netzwerk_ und den Zugang unter _Zugriff_.
-   **Platzierung**: Platzieren Sie den Switch über _Standort_ in seinem Rack und erfassen Sie die Höheneinheiten unter _Formfaktor_.
-   **Assets**: Pflegen Sie Firmware, Hersteller, Kosten und Garantie.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware
-   Netzwerkgerät

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Zugriff
-   Formfaktor
-   IP-Netzwerk
-   Standort
-   Modell
-   Buchhaltung
-   Kontakte
-   Garantie
-   Installiertes Betriebssystem
-   Netzwerkgerät
-   Hostname
