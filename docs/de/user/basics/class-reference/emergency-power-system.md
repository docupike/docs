# Notstromversorgung

Die Klasse **Notstromversorgung** dokumentiert Generatoren und ähnliche Systeme, die bei einem Ausfall die Stromversorgung übernehmen.
Die Objekte enthalten Standort, Modell, kaufmännische Daten und Garantie sowie die zuständigen Kontakte.

## Verwendung

-   **Platzierung**: Ordnen Sie die Anlage über _Standort_ dem Gebäude oder Raum zu, den sie absichert.
-   **Asset-Daten**: Erfassen Sie Hersteller, Seriennummer, Kosten und Garantie unter _Modell_, _Buchhaltung_ und _Garantie_.
-   **Zuständigkeiten**: Verknüpfen Sie den Wartungsdienstleister unter _Kontakte_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Infrastruktur

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Standort
-   Buchhaltung
-   Modell
-   Garantie
-   Kontakte
