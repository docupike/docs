# Router

Die Klasse **Router** dokumentiert Router, die Netze, Standorte und das Internet verbinden.
Die Objekte enthalten Netzwerkgerätedaten, IP-Adressen, Zugriff, Standort, Firmware und kaufmännische Daten.

## Verwendung

-   **Netzwerkrolle**: Erfassen Sie Typ und Betriebsmodus unter _Netzwerkgerät_ und den Namen unter _Hostname_.
-   **Adressierung**: Dokumentieren Sie die IP-Adressen unter _IP-Netzwerk_.
-   **Platzierung**: Platzieren Sie den Router über _Standort_ in seinem Rack und erfassen Sie die Größe unter _Formfaktor_.
-   **Assets**: Pflegen Sie Firmware, Hersteller, Kosten und Garantie.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware
-   Netzwerkgerät

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Zugriff
-   Formfaktor
-   IP-Netzwerk
-   Standort
-   Modell
-   Buchhaltung
-   Kontakte
-   Garantie
-   Installiertes Betriebssystem
-   Installierte Software
-   Hostname
-   Netzwerkgerät
