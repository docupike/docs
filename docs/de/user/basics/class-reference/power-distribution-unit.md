# Stromverteilereinheit

Die Klasse **Stromverteilereinheit** dokumentiert PDUs, die Strom innerhalb von Racks verteilen.
Verwaltbare PDUs können eine IP-Adresse erhalten, und jede Einheit wird im Standortbaum platziert.

## Verwendung

-   **Platzierung im Rack**: Platzieren Sie die PDU über _Standort_ in ihrem Rack.
-   **Verwaltungszugang**: Dokumentieren Sie die Management-IP-Adresse unter _IP-Netzwerk_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Infrastruktur
-   Versorgung

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   IP-Netzwerk
-   Standort
