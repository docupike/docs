# Virtualisierungshost

Die Klasse **Virtualisierungshost** dokumentiert physische Hosts, auf denen ein Hypervisor und virtuelle Maschinen laufen.
Die Objekte enthalten Hardware-, Netzwerk-, Standort-, Software- und kaufmännische Daten.

## Verwendung

-   **Hypervisor**: Erfassen Sie den Hypervisor unter _Installiertes Betriebssystem_ und Verwaltungswerkzeuge unter _Installierte Software_.
-   **Hardware**: Dokumentieren Sie Controller und Geräte und erfassen Sie die Größe unter _Formfaktor_.
-   **Netzwerk und Platzierung**: Erfassen Sie IP-Adressen unter _IP-Netzwerk_ und platzieren Sie den Host über _Standort_ in seinem Rack.
-   **Assets**: Pflegen Sie Hersteller, Kosten, Garantie und Kontakte.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Zugriff
-   Buchhaltung
-   Geräte
-   Controller
-   Formfaktor
-   IP-Netzwerk
-   Standort
-   Modell
-   Kontakte
-   Garantie
-   Installiertes Betriebssystem
-   Installierte Software
