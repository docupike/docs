# Rack

Die Klasse **Rack** dokumentiert Racks und Schränke in Rechenzentren und Verteilerräumen.
Ein Rack ist ein Standort-Container: Server, Switches, Patchpanels und PDUs werden darin platziert, und das Rack selbst steht in einem Raum.

## Verwendung

-   **Platzierung**: Platzieren Sie das Rack über _Standort_ in seinem Raum.
-   **Größe**: Erfassen Sie Höheneinheiten und Abmessungen unter _Formfaktor_.
-   **Inhalt**: _Standort (verknüpfte Objekte)_ listet alle Geräte, die im Rack verbaut sind.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Infrastruktur

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Standort (verknüpfte Objekte)
-   Formfaktor
-   Standort
