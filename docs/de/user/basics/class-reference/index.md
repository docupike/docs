# Klassenreferenz

i-doit up liefert 89 Standardklassen in 13 Kollektionen aus.
Jede Klasse hat eine eigene Seite mit kurzer Beschreibung, typischer Verwendung, ihren Kollektionen und den Kategorien, die ihr standardmäßig zugewiesen sind.
Kollektionen gruppieren Klassen thematisch.
Eine Klasse kann zu mehreren Kollektionen gehören und erscheint dann in mehreren Tabellen.
