# Lieferant

Die Klasse **Lieferant** dokumentiert Lieferanten von Hardware, Software und Dienstleistungen.
Die Objekte benennen die zuständigen Kontakte beim Lieferanten.

## Verwendung

-   **Lieferantenliste**: Bilden Sie jeden Lieferanten als eigenes Objekt ab.
-   **Kontakte**: Verknüpfen Sie Account Manager und Supportkontakte unter _Kontakte_.

## Kollektionen

Standardmäßig gehört die Klasse zu keiner Kollektion.

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Kontakte
