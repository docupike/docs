# Multifunktionsgerät

Die Klasse **Multifunktionsgerät** dokumentiert Geräte, die Drucken, Scannen, Kopieren und Faxen vereinen.
Die Objekte enthalten Druckerdaten, Netzwerk- und Zugangsdaten, Standort und kaufmännische Daten.

## Verwendung

-   **Druckerdaten**: Erfassen Sie Typ, Farbe, Duplex und Papierformat unter _Drucker_.
-   **Netzwerk**: Dokumentieren Sie die IP-Adresse unter _IP-Netzwerk_ und die Weboberfläche unter _Zugriff_.
-   **Assets**: Pflegen Sie Hersteller, Kosten und Garantie unter _Modell_, _Buchhaltung_ und _Garantie_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Zugriff
-   IP-Netzwerk
-   Standort
-   Modell
-   Drucker
-   Buchhaltung
-   Garantie
