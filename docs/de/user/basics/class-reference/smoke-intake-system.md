# Rauchansaugsysteme

Die Klasse **Rauchansaugsysteme** dokumentiert Rauchansaugsysteme, zum Beispiel in Serverräumen.
Die Objekte enthalten Modell, kaufmännische Daten und Garantie sowie die zuständigen Kontakte.

## Verwendung

-   **Modell**: Erfassen Sie Hersteller, Produkt-ID und Seriennummer unter _Modell_.
-   **Beschaffung und Garantie**: Pflegen Sie Inventarnummer, Kosten und Garantieende unter _Buchhaltung_ und _Garantie_.
-   **Zuständigkeiten**: Verknüpfen Sie Betreiber oder Wartungsdienstleister unter _Kontakte_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Schutzsystem

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Buchhaltung
-   Modell
-   Garantie
-   Kontakte
