# Daemon

Die Klasse **Daemon** dokumentiert Hintergrunddienste wie Webserver, Mailserver oder Agenten.
Die Objekte können mit Verträgen verknüpft werden.

## Verwendung

-   **Dienstlandschaft**: Bilden Sie jeden Daemon als eigenes Objekt ab.
-   **Verträge**: Verknüpfen Sie Supportverträge unter _Verträge_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Software

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Verträge
