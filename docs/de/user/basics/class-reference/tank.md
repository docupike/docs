# Tank

Die Klasse **Tank** dokumentiert Tanks, zum Beispiel Kraftstofftanks für Notstromaggregate.
Die Objekte enthalten Tankdaten, Modell, kaufmännische Daten und Garantie sowie die zuständigen Kontakte.

## Verwendung

-   **Tankdaten**: Erfassen Sie Kapazität und Inhalt unter _Tankinformationen_.
-   **Assets**: Pflegen Sie Hersteller, Kosten und Garantie unter _Modell_, _Buchhaltung_ und _Garantie_.
-   **Zuständigkeiten**: Verknüpfen Sie Betreiber oder Wartungsdienstleister unter _Kontakte_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Versorgung

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Tankinformationen
-   Buchhaltung
-   Modell
-   Garantie
-   Kontakte
