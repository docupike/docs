# Firewall

Die Klasse **Firewall** dokumentiert Firewalls, die Netze schützen und den Datenverkehr zwischen ihnen steuern.
Die Objekte enthalten Hostname und Netzwerkgerätedaten.

## Verwendung

-   **Netzwerkrolle**: Erfassen Sie Typ und Betriebsmodus unter _Netzwerkgerät_.
-   **Identifikation**: Erfassen Sie den Namen unter _Hostname_.
-   **Erweiterbar**: Weisen Sie der Klasse bei Bedarf weitere Kategorien wie _IP-Netzwerk_ oder _Standort_ zu.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Netzwerkgerät

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Hostname
-   Netzwerkgerät
