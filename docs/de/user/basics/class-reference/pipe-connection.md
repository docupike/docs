# Rohranschlüsse

Die Klasse **Rohranschlüsse** dokumentiert Rohranschlüsse, zum Beispiel für Kühlwasser oder Löschmittel.
Die Objekte enthalten Rohrdaten, Modell, kaufmännische Daten und Garantie sowie die zuständigen Kontakte.

## Verwendung

-   **Rohrdaten**: Erfassen Sie Durchmesser und Druck unter _Rohranschlussdetails_.
-   **Assets**: Pflegen Sie Hersteller, Kosten und Garantie unter _Modell_, _Buchhaltung_ und _Garantie_.
-   **Zuständigkeiten**: Verknüpfen Sie Betreiber oder Wartungsdienstleister unter _Kontakte_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Versorgung

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Rohranschlussdetails
-   Buchhaltung
-   Modell
-   Garantie
-   Kontakte
