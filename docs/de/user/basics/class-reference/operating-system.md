# Betriebssystem

Die Klasse **Betriebssystem** dokumentiert Betriebssysteme wie Windows Server, Ubuntu oder macOS.
Ein Betriebssystem-Objekt beschreibt das Produkt, seine Editionen und Versionen; Installationen werden mit Geräten verknüpft.

## Verwendung

-   **Produktdaten**: Erfassen Sie die Betriebssystemfamilie unter _Betriebssystem_, Editionen unter _Betriebssystem-Edition_ und Versionen unter _Softwareversion_.
-   **Installationen**: _Betriebssystem installiert auf_ listet alle Geräte, auf denen das Betriebssystem läuft.
-   **Verträge**: Verknüpfen Sie Lizenz- oder Supportverträge unter _Verträge_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Software

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Verträge
-   Betriebssystem
-   Betriebssystem installiert auf
-   Betriebssystem-Edition
-   Softwareversion
