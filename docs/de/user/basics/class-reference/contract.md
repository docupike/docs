# Vertrag

Die Klasse **Vertrag** dokumentiert Verträge wie Wartungs-, Support-, Leasing- oder Lizenzverträge.
Verträge werden mit den Objekten verknüpft, die sie abdecken, sodass Sie sehen, für welche Assets ein Vertrag gilt.

## Verwendung

-   **Vertragsdaten**: Erfassen Sie die Vertragsdetails unter _Vertrag_.
-   **Abgedeckte Objekte**: _Vertrag (verknüpfte Objekte)_ listet alle Objekte, die dem Vertrag zugeordnet sind.
-   **Kontakte**: Verknüpfen Sie Vertragspartner und interne Verantwortliche unter _Kontakte_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Information

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Vertrag
-   Vertrag (verknüpfte Objekte)
-   Kontakte
