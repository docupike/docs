# Cluster

Die Klasse **Cluster** dokumentiert Server-, Datenbank- oder Virtualisierungscluster als logische Einheit.
Das Cluster-Objekt enthält Standort- und Softwaredaten, die Mitgliedssysteme werden als eigene Objekte dokumentiert.

## Verwendung

-   **Logische Einheit**: Bilden Sie eine Gruppe von Servern oder Hosts als ein Objekt in der CMDB ab.
-   **Software**: Erfassen Sie Cluster-Software und Betriebssystem unter _Installiertes Betriebssystem_ und _Installierte Software_.
-   **Standort**: Ordnen Sie den Cluster über _Standort_ seinem Raum oder Gebäude zu.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Standort
-   Installiertes Betriebssystem
-   Installierte Software
