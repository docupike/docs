# Standort

Die Klasse **Standort** dokumentiert allgemeine Standorte, die weder Gebäude noch Etage noch Raum sind.
Ein Standort dieser Klasse ist ein Standort-Container mit eigener Adresse.

## Verwendung

-   **Standorthierarchie**: Platzieren Sie das Objekt im Standortbaum und nutzen Sie es als übergeordneten Standort für weitere Objekte.
-   **Adresse**: Hinterlegen Sie die Adresse unter _Adresse und Kontakt_.
-   **Übersicht**: _Standort (verknüpfte Objekte)_ listet alle Objekte an diesem Standort.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Lokation

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Standort (verknüpfte Objekte)
-   Standort
-   Adresse und Kontakt
