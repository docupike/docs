# Personengruppe

Die Klasse **Personengruppe** dokumentiert Gruppen von Personen, zum Beispiel Teams, Abteilungen oder Bereitschaftsdienste.
Eine Gruppe kann anstelle einzelner Personen als Kontakt zugeordnet werden.

## Verwendung

-   **Mitglieder**: Fügen Sie Personen unter _Mitglieder von Personengruppen_ zur Gruppe hinzu.
-   **Zuordnungen**: _Kontakte (verknüpfte Objekte)_ listet alle Objekte, für die die Gruppe zuständig ist.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Kontakt

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Mitglieder von Personengruppen
-   Kontakte (verknüpfte Objekte)
