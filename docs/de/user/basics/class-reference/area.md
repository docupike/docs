# Fläche

Die Klasse **Fläche** dokumentiert Flächen und Grundstücke, zum Beispiel einen Campus, ein Betriebsgelände oder ein Außengelände.
Eine Fläche ist ein Standort-Container, auf dem Gebäude und weitere Objekte platziert werden können.

## Verwendung

-   **Grundstücksdaten**: Erfassen Sie Katasteramt, Flurstück, Form und Untergrund unter _Flächendetails_.
-   **Standortdetails**: Erfassen Sie Nutzung, Eigentum und Größe unter _Standortdetails_ und die Adresse unter _Adresse und Kontakt_.
-   **Standorthierarchie**: Platzieren Sie Gebäude auf der Fläche und sehen Sie sie unter _Standort (verknüpfte Objekte)_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Lokation

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Standort (verknüpfte Objekte)
-   Standort
-   Flächendetails
-   Standortdetails
-   Adresse und Kontakt
