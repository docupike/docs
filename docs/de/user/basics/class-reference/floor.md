# Etage

Die Klasse **Etage** dokumentiert die Etagen eines Gebäudes.
Eine Etage ist ein Standort-Container zwischen Gebäude und Raum, sodass Sie große Gebäude nach Stockwerken gliedern können.

## Verwendung

-   **Standorthierarchie**: Platzieren Sie die Etage in ihrem Gebäude und nutzen Sie sie als übergeordneten Standort für Räume.
-   **Übersicht**: _Standort (verknüpfte Objekte)_ listet alle Objekte auf der Etage.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Infrastruktur

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Standort (verknüpfte Objekte)
-   Standort
