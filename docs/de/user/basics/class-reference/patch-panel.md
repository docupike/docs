# Patchpanel

Die Klasse **Patchpanel** dokumentiert Patchpanels, auf denen die strukturierte Verkabelung aufgelegt ist.
Die Objekte enthalten ihre Größe in Höheneinheiten und werden in einem Rack oder Raum platziert.

## Verwendung

-   **Platzierung im Rack**: Platzieren Sie das Panel über _Standort_ in seinem Rack.
-   **Größe**: Erfassen Sie Höheneinheiten und Abmessungen unter _Formfaktor_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Infrastruktur

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Formfaktor
-   Standort
