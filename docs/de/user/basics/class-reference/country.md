# Land

Die Klasse **Land** dokumentiert Länder als oberste Ebene des Standortbaums.
Ein Land ist ein Standort-Container, unter dem Städte und Gebäude platziert werden.

## Verwendung

-   **Standorthierarchie**: Nutzen Sie das Land als Wurzel für die Städte und Gebäude einer Region.
-   **Übersicht**: _Standort (verknüpfte Objekte)_ listet alle Objekte, die direkt im Land platziert sind.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Infrastruktur

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Standort (verknüpfte Objekte)
