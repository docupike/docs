# Systemkonto

Die Klasse **Systemkonto** dokumentiert technische Konten, zum Beispiel Dienstkonten oder Konten für Integrationen.
Standardmäßig hat die Klasse nur die Kategorie _Allgemein_.
Administratoren können der Klasse weitere Kategorien zuweisen.

## Verwendung

-   **Konten**: Bilden Sie jedes technische Konto als eigenes Objekt ab.
-   **Basisdaten**: Erfassen Sie Beschreibung, Zweck, Lebenszyklusphase und Tags unter _Allgemein_.
-   **Erweiterbar**: Weisen Sie der Klasse weitere Kategorien zu, wenn Sie mehr Attribute benötigen.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Kontakt

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
