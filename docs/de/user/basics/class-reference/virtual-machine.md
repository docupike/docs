# Virtuelle Maschine

Die Klasse **Virtuelle Maschine** dokumentiert virtuelle Maschinen.
Die Objekte enthalten Netzwerk- und Zugangsdaten, Betriebssystem, installierte Software und kaufmännische Daten.

## Verwendung

-   **Software**: Dokumentieren Sie Gastbetriebssystem und installierte Anwendungen.
-   **Netzwerk**: Erfassen Sie IP-Adressen unter _IP-Netzwerk_ und den Zugang unter _Zugriff_.
-   **Zuständigkeiten**: Verknüpfen Sie die verantwortliche Person oder das Betriebsteam unter _Kontakte_ und pflegen Sie Kosten unter _Buchhaltung_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Zugriff
-   IP-Netzwerk
-   Buchhaltung
-   Garantie
-   Kontakte
-   Installiertes Betriebssystem
-   Installierte Software
