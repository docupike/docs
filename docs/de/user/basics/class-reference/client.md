# Client

Die Klasse **Client** dokumentiert Desktop-PCs, Notebooks und andere Rechner, die von Mitarbeitenden genutzt werden.
Sie umfasst Hardware-, Speicher-, Anzeige-, Netzwerk-, Software- und kaufmännische Daten.

## Verwendung

-   **Hardware**: Erfassen Sie CPU, Speicher, Grafikkarte, Anzeige, Controller, Geräte und Volumes.
-   **Software**: Dokumentieren Sie Betriebssystem und installierte Anwendungen.
-   **Netzwerk**: Erfassen Sie IP-Adressen unter _IP-Netzwerk_ und den Namen unter _Hostname_.
-   **Asset-Management**: Pflegen Sie Kosten, Garantie, Verträge und die zuständige Person unter _Buchhaltung_, _Garantie_, _Verträge_ und _Kontakte_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware
-   Endanwendersystem
