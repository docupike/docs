# Supernetz

Die Klasse **Supernetz** dokumentiert Adressbereiche, die mehrere IP-Netze enthalten.
Die Objekte enthalten eine Netzwerkdefinition und listen ihre Subnetze und DHCP-Bereiche.

## Verwendung

-   **Adressplanung**: Erfassen Sie den Gesamtbereich unter _Netzwerkdefinition_.
-   **Hierarchie**: _Subnetze_ zeigt alle Netze, die zum Supernetz gehören.
-   **DHCP**: Dokumentieren Sie DHCP-Bereiche unter _DHCP-Bereiche_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Netzwerk

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Netzwerkdefinition
-   Subnetze
-   DHCP-Bereiche
