# Kabel

Die Klasse **Kabel** dokumentiert einzelne Kabel, zum Beispiel Strom- oder Datenkabel.
Neben dem Standort enthält jedes Kabel technische und kaufmännische Daten sowie die zuständigen Kontakte.

## Verwendung

-   **Technische Daten**: Erfassen Sie Querschnitt, Material, Anzahl der Adern und Befestigung unter _Kabelinformationen_.
-   **Platzierung**: Ordnen Sie das Kabel über _Standort_ seinem Raum oder Gebäude zu.
-   **Beschaffung**: Pflegen Sie Hersteller, Modell, Kosten und Garantie unter _Modell_, _Buchhaltung_ und _Garantie_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Infrastruktur
-   Versorgung

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Standort
-   Kabelinformationen
-   Buchhaltung
-   Modell
-   Garantie
-   Kontakte
