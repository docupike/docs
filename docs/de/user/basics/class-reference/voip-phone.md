# VoIP-Telefon

Die Klasse **VoIP-Telefon** dokumentiert IP-Telefone.
Die Objekte enthalten eine IP-Adresse, Firmware, Standort und Kontakte.

## Verwendung

-   **Netzwerk**: Erfassen Sie die IP-Adresse unter _IP-Netzwerk_.
-   **Platzierung**: Ordnen Sie das Telefon über _Standort_ seinem Raum zu.
-   **Zuordnung**: Verknüpfen Sie die nutzende Person unter _Kontakte_ und erfassen Sie die Firmware unter _Installiertes Betriebssystem_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   IP-Netzwerk
-   Standort
-   Kontakte
-   Installiertes Betriebssystem
