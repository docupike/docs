# Kabelrinne

Die Klasse **Kabelrinne** dokumentiert Rinnen und Trassen, über die Kabel durch Gebäude und Rechenzentren geführt werden.
Die Objekte enthalten ihre Abmessungen und werden im Standortbaum platziert.

## Verwendung

-   **Platzierung**: Ordnen Sie die Kabelrinne über _Standort_ dem Raum oder Gebäude zu, durch das sie verläuft.
-   **Abmessungen**: Erfassen Sie Breite, Höhe, Tiefe und Gewicht unter _Formfaktor_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Infrastruktur

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Formfaktor
-   Standort
