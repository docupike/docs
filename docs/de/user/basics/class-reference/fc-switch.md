# Fibre-Channel-Switch

Die Klasse **Fibre-Channel-Switch** dokumentiert Fibre-Channel-Switches, die Server und Storage in einem SAN verbinden.
Die Objekte enthalten Zugangs-, Netzwerk-, Standort-, kaufmännische und Firmwaredaten.

## Verwendung

-   **Platzierung**: Platzieren Sie den Switch über _Standort_ in seinem Rack und erfassen Sie die Höheneinheiten unter _Formfaktor_.
-   **Verwaltung**: Dokumentieren Sie die Management-IP-Adresse unter _IP-Netzwerk_ und die Zugangs-URL unter _Zugriff_.
-   **Firmware und Assets**: Erfassen Sie die Firmware unter _Installiertes Betriebssystem_ sowie Kosten und Garantie unter _Buchhaltung_ und _Garantie_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Zugriff
-   Formfaktor
-   IP-Netzwerk
-   Standort
-   Buchhaltung
-   Garantie
-   Installiertes Betriebssystem
