# Gerät

Die Klasse **Gerät** dokumentiert vorkonfigurierte Hardware-Appliances, zum Beispiel Security-, Backup- oder Storage-Gateways.
Die Objekte enthalten Netzwerkdaten, Zugangsinformationen, Standort, kaufmännische Daten und die installierte Software.

## Verwendung

-   **Netzwerk und Zugriff**: Dokumentieren Sie IP-Adressen unter _IP-Netzwerk_ sowie Management-URL und Zugangsdaten unter _Zugriff_.
-   **Platzierung**: Platzieren Sie das Gerät über _Standort_ in seinem Rack und erfassen Sie die Größe unter _Formfaktor_.
-   **Software**: Erfassen Sie Firmware oder Betriebssystem unter _Installiertes Betriebssystem_ und weitere Software unter _Installierte Software_.
-   **Asset-Daten**: Pflegen Sie Hersteller, Seriennummer, Kosten und Garantie unter _Modell_, _Buchhaltung_ und _Garantie_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Zugriff
-   Formfaktor
-   IP-Netzwerk
-   Standort
-   Modell
-   Buchhaltung
-   Kontakte
-   Garantie
-   Installiertes Betriebssystem
-   Installierte Software
