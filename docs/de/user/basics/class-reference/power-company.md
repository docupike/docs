# Stromversorgungsunternehmen

Die Klasse **Stromversorgungsunternehmen** dokumentiert die Versorger, die Ihre Standorte mit Strom beliefern.
Jedes Objekt kann einem Standort zugeordnet und mit den passenden Kontakten verknüpft werden.

## Verwendung

-   **Platzierung**: Ordnen Sie das Unternehmen über _Standort_ einem Gebäude oder einer Stadt zu.
-   **Kontakte**: Hinterlegen Sie Ansprechpartner oder die Störungshotline unter _Kontakte_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Infrastruktur

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Standort
-   Kontakte
