# Anwendung

Die Klasse **Anwendung** dokumentiert Softwareprodukte wie Office-Pakete, ERP-Systeme oder Werkzeuge.
Ein Anwendungsobjekt beschreibt das Produkt und seine Versionen; Installationen werden mit den Geräten verknüpft, auf denen es läuft.

## Verwendung

-   **Produktdaten**: Erfassen Sie den Hersteller unter _Software_ und die verfügbaren Versionen unter _Softwareversion_.
-   **Installationen**: _Software installiert auf_ listet alle Geräte, auf denen die Anwendung installiert ist.
-   **Verträge und Kosten**: Verknüpfen Sie Lizenz- oder Supportverträge unter _Verträge_ und erfassen Sie Kosten unter _Buchhaltung_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Software

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Buchhaltung
-   Verträge
-   Software
-   Software installiert auf
-   Softwareversion
