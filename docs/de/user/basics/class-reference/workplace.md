# Arbeitsplatz

Die Klasse **Arbeitsplatz** dokumentiert einzelne Arbeitsplätze oder Schreibtische.
Ein Arbeitsplatz wird in einem Raum platziert und steht für den Ort, an dem Clients, Monitore und Telefone genutzt werden.

## Verwendung

-   **Platzierung**: Platzieren Sie den Arbeitsplatz über _Standort_ in seinem Raum.
-   **Arbeitsplatzplanung**: Dokumentieren Sie jeden Schreibtisch eines Büros als eigenes Objekt im Raum.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Infrastruktur

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Standort
