# Telefonsystem

Die Klasse **Telefonsystem** dokumentiert Telefonanlagen und TK-Systeme.
Die Objekte enthalten Netzwerk- und Zugangsdaten, Standort, Firmware, kaufmännische Daten und Kontakte.

## Verwendung

-   **Verwaltung**: Dokumentieren Sie die IP-Adresse unter _IP-Netzwerk_ und die Administrationsoberfläche unter _Zugriff_.
-   **Platzierung**: Platzieren Sie die Anlage über _Standort_ in ihrem Rack oder Raum und erfassen Sie die Größe unter _Formfaktor_.
-   **Assets**: Pflegen Sie Firmware, Kosten, Garantie und den Dienstleister unter _Kontakte_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Zugriff
-   Formfaktor
-   IP-Netzwerk
-   Standort
-   Buchhaltung
-   Garantie
-   Kontakte
-   Installiertes Betriebssystem
