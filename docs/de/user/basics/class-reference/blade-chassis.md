# Blade-Chassis

Die Klasse **Blade-Chassis** dokumentiert Gehäuse, die Blade-Server und gemeinsam genutzte Komponenten wie Strom und Kühlung aufnehmen.
Ein Blade-Chassis ist ein Standort-Container: Blade-Server werden darin platziert, und das Chassis steht in einem Rack.

## Verwendung

-   **Platzierung**: Platzieren Sie das Chassis über _Standort_ in seinem Rack und erfassen Sie die Höheneinheiten unter _Formfaktor_.
-   **Enthaltene Blades**: Platzieren Sie Blade-Server im Chassis und sehen Sie sie unter _Standort (verknüpfte Objekte)_.
-   **Firmware**: Erfassen Sie die Management-Software des Chassis unter _Installiertes Betriebssystem_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Standort (verknüpfte Objekte)
-   Formfaktor
-   Standort
-   Installiertes Betriebssystem
