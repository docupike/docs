# Mobiltelefon

Die Klasse **Mobiltelefon** dokumentiert Mobiltelefone und Smartphones.
Die Objekte enthalten Netzwerk- und Zugangsdaten, kaufmännische Daten, Garantie und das mobile Betriebssystem.

## Verwendung

-   **Gerätedaten**: Erfassen Sie das mobile Betriebssystem unter _Installiertes Betriebssystem_ und Netzwerkdaten unter _IP-Netzwerk_.
-   **Asset-Daten**: Pflegen Sie Inventarnummer, Kosten und Garantie unter _Buchhaltung_ und _Garantie_.
-   **Standort**: Ordnen Sie das Telefon über _Standort_ einem Standort oder Raum zu.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Zugriff
-   IP-Netzwerk
-   Buchhaltung
-   Standort
-   Garantie
-   Installiertes Betriebssystem
