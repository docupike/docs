# Dienst

Die Klasse **Dienst** dokumentiert IT-Dienste, zum Beispiel E-Mail, Dateiablage oder ein ERP-System als Dienst.
Die Objekte benennen die zuständigen Kontakte.

## Verwendung

-   **Servicekatalog**: Bilden Sie jeden angebotenen Dienst als eigenes Objekt ab.
-   **Zuständigkeiten**: Verknüpfen Sie Service-Verantwortliche und Supportteam unter _Kontakte_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Information

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Kontakte
