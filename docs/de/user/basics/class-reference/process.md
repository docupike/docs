# Prozess

Die Klasse **Prozess** dokumentiert Geschäfts- und IT-Prozesse.
Die Objekte enthalten Prozessdetails wie Typ, Ziel und SLA und benennen die zuständigen Kontakte.

## Verwendung

-   **Prozessdetails**: Erfassen Sie Typ, Ziel, Nummer, SLA und bestehende Bedingungen unter _Prozessdetails_.
-   **Zuständigkeiten**: Verknüpfen Sie die prozessverantwortliche Person unter _Kontakte_.

## Kollektionen

Standardmäßig gehört die Klasse zu keiner Kollektion.

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Prozessdetails
-   Kontakte
