# Verkabelungssystem

Die Klasse **Verkabelungssystem** dokumentiert ein Verkabelungssystem als Ganzes, zum Beispiel das Backbone eines Gebäudes.
Jedes Objekt wird im Standortbaum platziert.

## Verwendung

-   **Platzierung**: Ordnen Sie das System über _Standort_ dem Gebäude oder Bereich zu, den es abdeckt.
-   **Struktur**: Dokumentieren Sie das System als Ganzes zusätzlich zu den einzelnen Kabeln, Leerrohren und Kabelrinnen.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Infrastruktur

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Standort
