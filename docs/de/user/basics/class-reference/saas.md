# SaaS

Die Klasse **SaaS** dokumentiert Cloud-Anwendungen, die Sie als Dienst nutzen, zum Beispiel CRM- oder Collaboration-Tools.
Die Objekte enthalten kaufmännische Daten, Verträge und Kontakte.

## Verwendung

-   **Abonnements**: Erfassen Sie Kosten und Bestelldaten unter _Buchhaltung_ und verknüpfen Sie das Abonnement unter _Verträge_.
-   **Zuständigkeiten**: Verknüpfen Sie Anbieter und interne Verantwortliche unter _Kontakte_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Software

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Buchhaltung
-   Kontakte
-   Verträge
