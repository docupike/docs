# Anzeige

Die Klasse **Anzeige** dokumentiert Monitore und andere Bildschirme.
Die Objekte enthalten Anzeigedaten wie Größe und Auflösung, das Modell und ihren Standort.

## Verwendung

-   **Anzeigedaten**: Erfassen Sie Größe, Auflösung, USB-Hub und Lautsprecher unter _Anzeige_.
-   **Modell**: Pflegen Sie Hersteller, Produkt-ID und Seriennummer unter _Modell_.
-   **Platzierung**: Ordnen Sie den Monitor über _Standort_ seinem Raum zu.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware
-   Anzeigegeräte
-   Endanwendersystem

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Formfaktor
-   Standort
-   Modell
-   Anzeige
