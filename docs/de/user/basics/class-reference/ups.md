# USV

Die Klasse **USV** dokumentiert unterbrechungsfreie Stromversorgungen, die Geräte vor kurzen Ausfällen und Spannungsschwankungen schützen.
Die Objekte enthalten ihre Größe, eine optionale Management-IP-Adresse und ihren Standort.

## Verwendung

-   **Platzierung**: Platzieren Sie die USV über _Standort_ in ihrem Rack oder Raum.
-   **Größe**: Erfassen Sie Höheneinheiten, Abmessungen und Gewicht unter _Formfaktor_.
-   **Verwaltungszugang**: Dokumentieren Sie die Netzwerk-Managementkarte unter _IP-Netzwerk_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Infrastruktur

## Zugewiesene Kategorien

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Allgemein
-   Formfaktor
-   IP-Netzwerk
-   Standort
