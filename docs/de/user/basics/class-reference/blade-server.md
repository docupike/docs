# Blade-Server

Die Klasse **Blade-Server** dokumentiert Servermodule, die in einem Blade-Chassis betrieben werden.
Sie umfasst CPU, Speicher, Storage, Netzwerk, Software und kaufmännische Daten.

## Verwendung

-   **Hardware**: Erfassen Sie CPUs, Arbeitsspeicher und Storage unter _CPU_, _Speicher_, _Controller_, _Geräte_ und _Volumes_.
-   **Platzierung**: Platzieren Sie das Blade über _Standort_ in seinem Chassis.
-   **Software und Netzwerk**: Dokumentieren Sie Betriebssystem, installierte Software und IP-Adressen.
-   **Verträge und Assets**: Verknüpfen Sie Supportverträge unter _Verträge_ und pflegen Sie Kosten und Garantie unter _Buchhaltung_ und _Garantie_.

## Kollektionen

Standardmäßig gehört die Klasse zu den folgenden Kollektionen:

-   Hardware

Die folgenden Kategorien sind der Klasse standardmäßig zugewiesen:

-   Zugriff

-   CPU
-   Geräte
-   Controller
-   IP-Netzwerk
-   Standort
-   Speicher
-   Modell
-   Buchhaltung
